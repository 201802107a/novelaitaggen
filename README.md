# 태그 조판소

한국어로 검색해서 탭으로 고르고, Danbooru 태그 프롬프트를 뽑는 도구.
NovelAI / SDXL(Illustrious·NoobAI) 계열에 그대로 붙여넣을 수 있습니다.

- 화면 표시 항목 4,150개 / 분류 319개 — 데이터는 `tags.json`에서 읽음
- 별도 백엔드 불필요. GitHub Pages 또는 로컬 HTTP 서버에서 실행
- 자주 쓰는 조판을 이름 붙여 **보관함**에 저장
- 선택한 태그를 탭하면 강조 조절: `[tag]` → `tag` → `{tag}` → `{{tag}}`
- 화면 표시·프롬프트 복사는 `long_hair` → `long hair`처럼 `_`를 공백으로 변환
- 영문 태그는 공백·언더스코어 어느 표기로 검색해도 찾을 수 있음

생성용 프롬프트의 미리보기와 복사 결과는 같은 공백 표기를 사용합니다.
기존 보관함에서 불러온 태그와 무작위 조판에도 적용되며 `{강조}`와 `[약화]`는 유지됩니다.
`tags.json`, 보관함 데이터, `presets.json` 백업은 태그 식별과 재사용을 위한
원래 키를 유지합니다.

## GitHub Pages로 올리기

1. 새 저장소 생성 (**Public** — 무료 계정은 공개 저장소만 Pages를 쓸 수 있음)
2. `index.html`, `tags.json` 업로드 (`presets.json` 은 선택)
3. Settings → Pages → Source를 **Deploy from a branch**, 브랜치 `main` / `/ (root)`
4. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열림

`raw.githubusercontent.com` 링크로는 열리지 않습니다. 반드시 Pages를 켜세요.

## 보관은 어디에 되나

두 군데로 나뉩니다. **고칠 수 있는 곳이 다릅니다.**

### presets.json — 저장소 (오래 남는 쪽)

`index.html` 옆의 `presets.json` 을 시작할 때 읽어서 **점선 테두리 칩**으로 보여줍니다.

- 기기를 바꿔도, 브라우저 데이터를 지워도 남습니다
- 커밋 이력이 남아 실수로 지워도 되돌릴 수 있습니다
- **앱에서는 수정·삭제되지 않습니다.** GitHub 저장소에서만 고칠 수 있고,
  저장소 쓰기 권한은 GitHub 계정이 판단하므로 소유자만 가능합니다

캐릭터 외모처럼 매번 똑같이 들어가야 하는 묶음을 여기에 둡니다.

### 보관함 — 브라우저 (작업용)

`＋ 지금 조판 보관` 으로 저장한 것은 브라우저의 localStorage 에 들어갑니다.
같은 주소로 다시 오면 남아 있지만, 아래 경우에는 사라집니다.

- 다른 기기, 다른 브라우저
- 방문 기록 / 사이트 데이터 삭제, 시크릿 모드 종료
- iOS Safari 에서 한동안 열지 않은 경우
  → **홈 화면에 추가** 해두면 훨씬 오래 유지됩니다

## 보관함을 저장소로 올리기

토큰이나 별도 설정이 필요 없습니다. 복사해서 붙여넣으면 끝입니다.

1. 앱에서 조판을 만들고 `＋ 지금 조판 보관` 으로 이름을 붙입니다
2. `presets.json 복사` — 저장소 항목과 보관함 항목을 합쳐
   `presets.json` 파일 전체 내용이 클립보드에 담깁니다
3. 저장소에서 `presets.json` 을 열고 연필 아이콘 → 전체를 지우고 붙여넣기 → Commit
   (모바일 브라우저에서도 됩니다)
4. 앱을 새로고침하면 그 항목이 점선 칩으로 바뀝니다.
   같은 이름의 로컬 사본은 자동으로 정리됩니다

`가져오기` 는 같은 형식의 JSON 을 보관함으로 되돌립니다. 기기를 옮길 때 씁니다.

## presets.json 형식

```json
[
  {
    "name": "유나 · 기본 외모",
    "tags": [
      { "ko": "긴 머리",  "tag": "long_hair",  "w": 0 },
      { "ko": "검은 머리", "tag": "black_hair", "w": 0 },
      { "ko": "파란 눈",  "tag": "blue_eyes",  "w": 1 }
    ]
  }
]
```

`w` 는 강조입니다. `-1` → `[tag]`, `0` → `tag`, `1` → `{tag}`, `2` → `{{tag}}`.

## 데이터 출처

원래 목록은 2022년 11월 기준 자료입니다. 2026-09-20에 기존 목록을
[2026-09-12 Danbooru 기반 사전 스냅샷](https://github.com/GuWuW/danbooru-dict/blob/e046fa867f140e87e21524c25550fd55611da4cf/tags.csv)
124,735개와 대조했습니다. 공식 실시간 API는 접속 시간 초과로 확인하지 못했으므로,
**현재 Danbooru 전체 목록과의 완전 동기화를 뜻하지 않습니다.**

- 스냅샷에 존재하는 태그의 대소문자·공백 표기 371곳을 정리했습니다.
- 누락된 기본 태그 94개를 한국어 이름과 기존 분류에 추가했습니다.
- 기존 한국어 이름, 분류, `nsfw` 값과 미확인 프롬프트는 유지했습니다.
- 변경 전 4,167행 → 변경 후 4,261행입니다. 자리표시 문자가 있는 111행은
  기존 화면 로직에서 건너뛰므로 화면에는 4,150개 항목이 표시됩니다.
- 화면에서는 소문자·언더스코어 변환, 분리된 법인격 병합, 행 내부 중복 제거를 수행합니다.
- **현재 화면은 `nsfw` 값을 필터로 사용하지 않습니다.**

대조 근거, 미확인 별칭 199개, 미수록 태그, 전체 변경 내역은
[비교 보고서](reports/README.md)를 참고하세요. 별칭은 과거 매핑이 섞여 있을 수 있어
자동 치환하지 않았으며, 스냅샷 미수록을 이유로 태그를 삭제하지 않았습니다.

### 다시 비교하기

Python 3.10 이상이 필요하며 추가 패키지는 없습니다. 참조 CSV는
`태그명,분류번호,게시물수,별칭들` 형식이고, 별칭 셀 내부 구분자는 쉼표입니다.
다섯 번째 열 이후의 번역 정보는 읽지 않습니다.

```bash
git clone https://github.com/GuWuW/danbooru-dict.git ../danbooru-dict
git -C ../danbooru-dict checkout e046fa867f140e87e21524c25550fd55611da4cf
python scripts/audit_tags.py --reference ../danbooru-dict/tags.csv --source-url https://github.com/GuWuW/danbooru-dict/blob/e046fa867f140e87e21524c25550fd55611da4cf/tags.csv --source-date 2026-09-12 --additions data/reviewed-additions.json --output reports/current
```

기본 실행은 비교 CSV, 요약 JSON, 변경 내역 및 제안 데이터만 생성합니다.
검토 후 `--apply`를 붙이면 스냅샷으로 확인한 표기와 검토된 추가 항목만 반영합니다.
별칭 후보, 스냅샷 미수록 태그, 자리표시 문자는 자동 치환·삭제하지 않습니다.
참조 파일을 바꿀 때는 실제 원본 URL과 스냅샷 날짜도 함께 지정해야 합니다.

```bash
python -m unittest discover -s tests -v
```

## 알아둘 점

**Danbooru 태그의 존재 여부와 이미지 모델의 인식 여부는 다릅니다.**
특히 품질 프롬프트는 Danbooru에 없더라도 모델에서 유효할 수 있습니다.
**품질 태그는 모델마다 권장 조합이 다릅니다.** 하단 프리셋을 쓰거나,
사용하는 체크포인트 카드에 적힌 권장 프롬프트를 따르세요.
