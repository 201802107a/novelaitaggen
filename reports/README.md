아래 집계는 **표기 정리 후 고유 태그 기준**이므로 행 수와 다릅니다.

스냅샷에 없다는 것은 Danbooru에 없거나 잘못된 태그라는 뜻이 아닙니다.
수록 하한 미달, 폐기·변경, 사용자 프롬프트 등 여러 원인이 가능합니다.

별칭 후보 예: `china_dress` → `qipao`, `animation` → `animated`,
`bar` → `bar_(place)`. 이들은 제안만 기록했으며 이번에는 치환하지 않았습니다.

## 적용한 변경

- 소문자·공백 표기 371곳 정리. 예: `Lowres` → `lowres`.
  원래 화면이 같은 방식으로 출력하던 표기를 원본 데이터에도 반영한 것입니다.
- 스냅샷에 존재하는 기본 태그 94개를 한국어 이름과 함께 추가.
  예: `smile`, `simple_background`, `long_sleeves`, `grey_hair`, `from_side`, `indoors`.
- 신규 항목은 [검토된 추가 목록](../data/reviewed-additions.json)에 별도로 기록.
  전체 Danbooru 사전 일괄 수입이 아닌 기존 한국어 분류에 맞춘 보강입니다.
- 기존 행의 순서, 한국어 이름, 분류, `nsfw` 값은 유지했습니다. 기존 태그·행 삭제 없음.
